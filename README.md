# Helpdesk Ticket Management System

A full-stack Helpdesk Ticket Management System
built with React, Node.js, Express.js, PostgreSQL,
and Prisma.

## Technology Stack

### Frontend
- React.js
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM

### Database
- PostgreSQL

### DevOps
- Docker
- Docker Compose
- Git & GitHub

## Core Features

- User Authentication
- Role-Based Access Control
- Customer Management
- Ticket Management
- Ticket Assignment
- Ticket Status Workflow
- Comments and Attachments
- SLA Management
- Notifications
- Dashboard and Reports

## Future Features

- AI Ticket Classification
- AI Smart Reply
- AI Ticket Summarization
